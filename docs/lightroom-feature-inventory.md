# Lightroom feature inventory for a parity audit

**Research date:** 2026-08-23. **Evidence rule:** first-party Adobe documentation only. A feature is listed when Adobe documents it; a limitation is listed only when Adobe documents that limitation. This is a capability inventory, not a claim that any particular app implements a feature.

## Product surfaces and version baseline

Adobe uses **Lightroom Ecosystem** for the cloud-oriented product family. It includes Lightroom on desktop, mobile, and the web. **Lightroom Classic** is the separate catalog-first desktop product. Adobe’s comparison page was last updated 2026-03-05; later release notes and help pages below supersede an older row when they conflict. Adobe’s supported-version page lists Lightroom desktop 9.x and mobile 11.x as current as of 2026-02-11; Adobe’s June 2026 release notes describe desktop 9.4 and Classic 15.4 features.

| Surface | Role in this inventory | Adobe-documented boundary |
|---|---|---|
| **Lightroom desktop** (`LR-d`) | Cloud library plus a Local section for device folders | Cloud originals are optional; local files can be browsed and edited without import or sync. [Access photos (updated 2026-03-27)](https://helpx.adobe.com/lightroom-cc/using/access-photos.html) |
| **Lightroom mobile** (`LR-m`) | iOS and Android capture, import, edit, organize, sync, and share | Free core editing/organization; premium unlocks advanced tools and cloud storage. [Install Lightroom mobile (updated 2026-06-05)](https://helpx.adobe.com/lightroom/mobile/get-started/download-and-install-lightroom.html) |
| **Lightroom web** (`LR-w`) | Browser access to the cloud library, editing, search, sharing, and community | Requires a supported browser and internet connection. [Web technical requirements (updated 2026-04-28)](https://helpx.adobe.com/lightroom-cc/web/get-set-up/learn-the-basics/technical-requirements.html) |
| **Lightroom Classic** (`LrC`) | Local originals, folders, `.lrcat` catalog(s), modules, plug-ins, and optional ecosystem sync | Classic-to-cloud sync uploads Smart Previews, not originals; cloud-to-Classic downloads originals. [Sync FAQ (updated 2026-04-09)](https://helpx.adobe.com/lightroom-classic/kb/sync-faq.html) |
| **Adobe Camera Raw** (`ACR`) | Shared raw/camera/lens support reference and editing engine context | The supported-camera table explicitly maps minimum Lightroom and Classic versions. [Supported cameras (updated 2026-07-16)](https://helpx.adobe.com/camera-raw/kb/camera-raw-plug-supported-cameras.html) |

## Executive differences to preserve in an audit

| Architectural difference | Lightroom evidence | What a parity claim must distinguish |
|---|---|---|
| Local-first vs cloud-first | Classic stores catalog records and links to local originals; the ecosystem can upload originals, keep them in the cloud, and optionally expose local folders. [Feature comparison (updated 2026-03-05)](https://helpx.adobe.com/lightroom-classic/desktop/kb/lightroom-feature-comparison.html), [Local/cloud access (updated 2026-03-27)](https://helpx.adobe.com/lightroom-cc/using/access-photos.html) | “Local folder library” covers only part of Lightroom. Full parity also needs a cloud-originals model, storage controls, and cross-device sync. |
| Classic catalog power vs ecosystem sharing | Classic supports multiple catalogs, Smart Collections, full IPTC editing, tethering, plug-ins, print, books, maps, and web galleries; the ecosystem adds cloud sharing, invitations, community, and web/mobile access. [Feature comparison](https://helpx.adobe.com/lightroom-classic/desktop/kb/lightroom-feature-comparison.html) | Compare each surface separately. Do not treat Classic and cloud Lightroom as one identical feature set. |
| Same core edit engine, surface-specific gaps | Most global/local controls exist in both; web cannot update several AI settings and video has a narrower edit control set. [AI edit status (updated 2026-04-28)](https://helpx.adobe.com/lightroom/web/edit-photos/manage-ai-edits.html), [Desktop video editing (updated 2024-05-21)](https://helpx.adobe.com/lightroom/desktop/edit-videos/edit-videos.html) | “Supports masking” or “supports video” must include the exact surface and the unsupported subfeatures. |
| Classic modules vs ecosystem connections | Classic has Book, Slideshow, Print, Map, Web, Publish Services, and third-party SDK plug-ins; ecosystem has Connections, shared albums, web galleries, and print partners. [Classic Help index](https://helpx.adobe.com/lightroom-classic/desktop.html), [Feature comparison](https://helpx.adobe.com/lightroom-classic/desktop/kb/lightroom-feature-comparison.html) | A full parity target needs both the creative-output modules and the cloud collaboration paths, or an explicit scope decision. |

## Feature-parity checklist for the audit

Use this as the minimum set of capability families to test against the app. “Present” should mean the behavior and the Adobe-documented limitation match, not merely that a similarly named button exists.

- **Storage model:** local folders, cloud originals, optional local archive, Smart Previews, reduced/original downloads, deleted recovery, offline edits.
- **Ingest:** folder/card import, copy/move/add/Copy as DNG, duplicate detection, import presets, metadata/keyword templates, filename templates, auto-import, tethered capture, mobile camera.
- **Library model:** folders, albums/collections, nested containers, Smart Collections/Albums, stacks, target collection, rename, multiple catalogs, catalog backup/upgrade/export, missing-file relinking.
- **Organization/search:** ratings, flags, color labels, keywords and hierarchy, full IPTC/GPS, capture-time shifting, People view, natural-language search, facets, duplicate detection, auto-stack.
- **Review/culling:** Grid/Loupe/Detail/Compare/Survey, zoom, second display, Assisted Culling scores and faces, batch culling actions.
- **Editing:** global tone/color/detail/optics/geometry/calibration, crop/straighten, red eye, heal/clone/remove, lens blur, soft proofing, non-destructive reset.
- **Masking:** brush/gradients/range, Subject/Sky/Background/Object/People/Landscape selections, person subfeatures, add/subtract/intersect/invert, batch mask paste, AI update status.
- **AI:** Denoise, Raw Details, Super Resolution, Generative Upscale, AI Sharpen, Generative/Content-Aware Remove, People/Reflection/Dust/Blemish removal, Assisted Culling, Generate Video, Content Credentials.
- **Preset/profile workflow:** import/create/update/favorite/filter, Amount slider, Premium/Adaptive/Recommended, camera profiles, custom profiles, raw defaults, ISO-adaptive presets, cloud sync.
- **Advanced image:** raw/camera/lens coverage, DNG/HEIF/AVIF/JPEG XL/PSD/PSB/PNG/WebP/TIFF/CMYK, HDR edit/output, HDR/panorama/HDR panorama merge, gain maps, HDR display behavior.
- **History/batch:** Classic History/Snapshots/Virtual Copies vs ecosystem Versions/Duplicates, Before/After/Reference, copy/paste/Sync/Auto Sync, sidecars and external metadata round trips.
- **Video:** import/play/scrub/poster/frame capture/trim, Profile/Light/Color/Effects, preset compatibility, MP4/Original export, H.264/DPX/4K Classic export, HDR video platform limits, generated video.
- **Output:** export formats/options, resize/resolution/color space/sharpening/metadata/watermark, Content Credentials, batch export, Publish Services, Connections, shared links/QR/embed/roles/comments/downloads, print, books, slideshows, maps, web galleries.
- **Extensibility and operations:** Photoshop/external editors, Classic Lua plug-ins/SDK, cloud/community/learning, OS/browser/device support, keyboard/screen reader, GPU/AI fallbacks, sync failure recovery, localization.
