Edit `darkroom.af` in Affinity. `darkroom.svg` is the vector export and `darkroom.png` is the 1024 × 1024 sRGB export with a transparent background.

The PNG supplies the Electron window and Dock icon. The macOS package uses `darkroom.icns`; Windows uses `darkroom.ico`; Linux uses the PNG. `app/favicon.ico` contains 16, 32, and 48 pixel versions.
